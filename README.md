# CEO Daily Brief: a concept for Boom

Blake Scholl posted that he's hiring a Chief of Staff and said to find a quality way to reach him. This is mine: the first artifact I'd build in the role, a daily operating brief, dated the morning I made it.

The structure is the point: decision and action oriented, items tied to owners and dates, recommendations where appropriate.

Every figure is invented, except the publicly reported order book. Not affiliated with or endorsed by Boom Supersonic.

Hand-written HTML and CSS. No framework, no build step, no JavaScript. Type is Archivo.
